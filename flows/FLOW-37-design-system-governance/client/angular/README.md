# FLOW-37 design-system-governance Angular Shell

This Angular application renders stack compatibility, prompt exclusion, design debt, and token consistency evidence surfaces for the .NET/Angular portability gate.

## Commands

```powershell
npm test -- --watch=false
npm run build
npm run serve:evidence
npm run capture:evidence
```

The evidence server listens on `http://127.0.0.1:4337`.
